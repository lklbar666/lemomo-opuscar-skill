# 制片工作流（Workflow）

## 三份工作文件（Agent 的"导演手册"）

| 文件 | 作用 | 关注点 |
|---|---|---|
| DIRECTOR.md | 导演法 | 故事、声音、节奏、镜头、表演、自检清单 |
| TECHNIQUE.md | 技术构建 | 逐帧渲染、配音、音乐、混音 |
| styles/<风格>/STYLE.md | 风格定义 | 该风格"看起来和听起来"是什么样；故事由你提供 |

Agent 首次使用会把指南、工具与风格提示词下载到 `~/lemo-opuscar`，所有影片共用这份库。

## 制片流水线

1. **需求一句话**：`时长 + 风格 + 主题 + 旁白/音乐偏好`。
   例："做一支45秒水彩风短片，讲我家经营的咖啡农场，温暖女声旁白。"
2. **前置确认（只问一次）**：
   - 主题里 Agent 无法自己决定的点；
   - 你是否有自有声音/音乐/素材；
   - 是否要先看分镜板（真实风格下的关键镜头预览）。
3. **代理工作（30-60分钟）**：
   - 画面：Canvas / WebGL 页面逐帧渲染；
   - 音乐：免费素材库原创编排；
   - 声音：TTS 旁白；
   - 不使用视频生成模型，不使用现成素材。
4. **成片质检**：按需调整质量、排版、片头片尾、字幕、音量。
5. **交付**：默认 1920×1080 @ 24fps；其他尺寸按需重渲染。

## 改编风格流程（Make a Style Your Own）

```
1. 用户点名：把某风格改成自己的版本
2. Agent 说明三档可改项：安全改动 / 改变气质的改动 / 一改就变风格的禁区
3. 用户说出改动并命名
4. Agent 写入 ~/lemo-my-styles/<名字>/（库外，独立于更新）
5. 输出一帧风格对比图（新版 vs 原版）
6. 用户确认后，制作 15-30 秒测试片展示全部改动
7. 之后按普通风格点名使用："用我的『夜浮世绘』做一支30秒影片"
```

## 输出参数

- 默认 1920×1080 @ 24fps；其他尺寸需显式要求。
- 环境：Node 20+、ffmpeg、Python 3.11+（或 uv）；其余依赖自动安装。
- 单支片预计 30-60 分钟 Agent 时长与可观 token 消耗。

| 数据/快讯/反转 | 字幕新闻、数据叙事、等距信息图 |

| 调查/复盘/辟谣 | 视觉调查、档案灯台、卫星简报 |
| 城市/地理/工程 | 工程简报板、点云测绘、白模投影 |
| 产品/发布 | 暗色科技发布、全息界面、玻璃产品渲染 |
| 故事/情感 | 水彩、水墨、蜡笔绘本、皮影 |
